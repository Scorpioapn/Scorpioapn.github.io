# 时间官产品协调性设计

## 目标

让 `index.html` 与经典、Modern 两个 agenda 页面被一眼识别为同一套产品，同时保持时间官现场控时的速度、可读性和既有行为。

## 选定方向

采用“Editorial Control Room”方向：紧凑品牌页头 + 可扫描左侧议程栏 + 开放式计时主舞台 + 可折叠详情检查区。结构与现有 DOM 高度吻合，能在不改计时/同步/记录逻辑的前提下实现视觉升级。吸收“Stage Signal Board”方向的上一项/下一项清晰度，但不新增数据模型或独立页面。

## 视觉系统

- 品牌：使用 `assets/toastmasters-logo-color-png.png`；产品名为“畅言中文 · 时间官”，副标为 `TOASTMASTERS LIVE CONSOLE`。
- 颜色：主蓝 `#004165`、深蓝 `#00334F`、酒红 `#772432`、工作区 `#F2F4F6`、白色表面 `#FFFFFF`、正文 `#16232E`、边框 `#DFE5EA`。
- 字体：界面采用 `Noto Sans SC / PingFang SC / Microsoft YaHei`；计时数字采用 `Oswald / DIN Alternate / Bahnschrift` 等本机压缩数字字体。
- 几何：6/10/14px 圆角；使用间距、对齐和细分隔线组织层级；阴影只用于浮动控制区，且保持轻量。
- 状态：绿/黄/红只表达时间语义。计时主舞台保持白底，以顶部窄色条、状态标签和进度条表达状态，文字继续明确说明状态。

## 桌面布局

- 64px 产品页头横跨全宽，左侧品牌，右侧提供“现场计时”当前态以及经典/Modern 议程入口。
- 248px 左侧议程栏展示编号、环节名和当前/完成状态；内容可滚动。
- 主工作区继续使用现有 `focus-card + side-panel` 网格。详情收起时计时主舞台占满；展开时出现 320–380px 检查区。
- 计时主舞台保留当前环节、规则摘要、超大读数、状态说明、发言人/题目、下一环节和固定主操作区。

## 移动端

- 768px 以下隐藏桌面品牌页头和议程栏，保留现有 `mobile-topbar`、底部浮动控制坞和 bottom sheet。
- 顶栏中心同时显示“畅言中文 · 时间官”和状态，避免只看到孤立状态标签。
- 计时主舞台使用 14px 圆角、白底、16px 页面边距；按钮保持至少 44px 可触达高度。
- 不改变 `setMobileTab`、sheet 开关、记录、报告、议程调整和主操作绑定。

## 数据与行为边界

- 不修改任何 localStorage key、议程同步、记录持久化、计时状态机或导出逻辑。
- 不清空记录，不覆盖已开始/已完成的现场议程状态，不建立反向写回。
- 只增加语义化品牌/导航标记并重写样式；既有元素 ID 与事件绑定保持不变。

## 验证

- 静态契约：品牌页头、Logo、agenda 导航、Toastmasters token、桌面网格和移动端覆盖样式存在。
- 自动化：`npm test` 与 `git diff --check`。
- 浏览器：1440×1000、390×844、412×915；无横向滚动；开始/暂停/继续/结束记录、议程 sheet、更多操作与详情检查区可用；控制台无错误。
- 视觉 QA：线上时间官截图 + 选定设计图作为双重视觉真值，与本地实现同视口并排比较；修复全部 P0/P1/P2 后通过。
