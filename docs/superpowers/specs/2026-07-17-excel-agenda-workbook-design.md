# 畅言议程生成器无宏 Excel 版设计

## 目标

将现有 `agenda_generator.html` 的核心工作流迁移为一个普通 `.xlsx` 工作簿。工作簿不使用 VBA、Office Scripts、加载项或外部构建系统，依靠 Microsoft 365 Excel 的动态数组、表格、数据验证、条件格式和打印设置完成数据录入、接龙解析、模板切换、自动排程与 A4 输出。

视觉目标是尽量接近现有议程成品：保留 Toastmasters 深蓝与酒红配色、顶部会议信息、左侧信息卡片、右侧分组议程、项目行底色、二维码与页脚。设计还原度以约 85% 至 90% 为合理目标，同时保证单元格仍可编辑、公式可审计、打印结果稳定。

## 平台与交付物

- 主要平台：新版 Microsoft 365 Excel 桌面版，Windows 与 macOS。
- 辅助平台：Excel 网页版可用于编辑和协作，但最终分页与 PDF 验收以桌面版为准。
- 文件格式：普通 `.xlsx`，文件名为 `畅言议程生成器-无宏版.xlsx`。
- 云端协作：使用 OneDrive 或 SharePoint 的自动保存和共同编辑，替代浏览器 `localStorage` 与 Supabase 同步。
- 不包含宏，因此不会出现“启用内容”安全提示。

## 工作簿结构

### 操作台

操作台是默认入口，包含：

- 会议信息输入：期数、主题、今日一词、例会经理、日期、开始时间、结束时间和地点。
- 议程来源下拉框：`接龙导入`、`议程模板`、`手工编辑`。
- 模板下拉框：至少包含 `常规例会模板` 与 `即兴马拉松模板`。
- 接龙文本粘贴区和解析状态。
- 解析出的会议字段、角色和议程预览。
- 一页容量、缺失负责人、可疑日期和时间范围等警告。
- A4 议程与打印操作的简短说明。

黄色填充表示可编辑输入；公式结果、状态和只读预览使用白色或浅灰背景。

### 议程编辑

议程编辑表按稳定项目键组织，每行至少包含：

- 项目键
- 分组编号与分组名称
- 项目标题与说明
- 时长显示文本
- 排程分钟数
- 默认负责人或角色来源
- 修正标题
- 修正说明
- 修正时长
- 修正排程分钟数
- 修正负责人
- 最终开始时间

最终值优先级统一为：

`手工修正值 > 当前议程来源值 > 默认值`

修正列为空时恢复自动结果。首版使用固定 60 行编辑容量；用户只在黄色修正列填写、清空或复制内容，不对整张表插入、删除或排序行，以保证排程辅助列和 A4 行映射稳定。

### A4议程

A4 议程只负责展示与打印，不作为主要输入区。它从统一议程数据和基础资料中读取最终值。

- A4 纵向，固定打印区域和页边距。
- 顶部使用深蓝页眉，包含 Logo、英文会名、中文会名、主题、今日一词、经理、日期、时间和期数。
- 左侧约占页面宽度 30%，展示关于我们、计时规则、二维码、会员团队和下期预告。
- 右侧约占页面宽度 70%，展示时间、内容、时长和负责人。
- 深蓝表头、酒红分组带、浅蓝即兴行、浅绿备稿或分享行、浅灰茶歇行。
- 隐藏工作表网格线、行号和列标，打印结果不出现编辑辅助元素。

分组带不使用动态合并单元格。每个组的分组列连续使用相同填充和无内横线样式，只在组的中间行显示编号和名称，从视觉上模拟可随行数变化的纵向合并色带。

标准 A4 页最多容纳 30 个议程项目。超过容量时操作台显示警告，数据不截断，并由第二页扩展区域承接超出项目。

### 模板库

模板库使用标准 Excel 表格保存：

- 模板名称
- 项目键
- 分组顺序、编号和名称
- 项目顺序
- 标题与说明
- 时长显示文本
- 排程分钟数
- 默认负责人或角色键
- 行类型和配色类型

模板库首版迁移现有的常规例会和即兴马拉松模板。新增模板通过在表格末尾复制项目行并统一更换模板 ID、模板名称和项目键完成，无需修改公式；下拉清单自动去重读取表格内容，首版读取上限为第 1000 行。

### 基础资料

基础资料包含俱乐部中英文名称、介绍、愿景、会议规则、官员团队、下期预告和图片说明。Logo、二维码和海报采用 Excel 内嵌图片，用户通过“更改图片”替换；首版不自动从本地路径或网络下载图片。

### 计算区

计算区保存动态数组公式、命名范围和验证列表，默认隐藏并保护，避免普通编辑破坏公式。A4 议程和操作台只引用计算区的最终结果。

## 数据流

三个来源先转换为相同结构，再进入统一议程数据：

1. 接龙文本由公式解析为会议字段、角色和议程项目。
2. 模板选择通过 `FILTER` 等公式取得对应模板行。
3. 手工编辑读取用户维护的议程表。
4. 修正列使用非空优先规则覆盖来源结果。
5. 排程公式依据会议开始时间和排程分钟数递推开始时间。
6. A4 议程只读取统一后的最终字段。

改变来源下拉框相当于网页中的“确认导入”或“更换模板”。仅粘贴接龙文字不会直接改变 A4 议程，直到来源切换为 `接龙导入`。

## 接龙解析

接龙解析使用 Microsoft 365 公式，例如 `LET`、`TEXTSPLIT`、`TEXTBEFORE`、`TEXTAFTER`、`FILTER`、`XLOOKUP`、`TOCOL`、`TAKE` 和 `IFERROR`。公式必须通过命名公式或分段辅助列保持可读，不把全部逻辑塞进一个不可维护的超长公式。

首版规则包括：

- 支持换行文本和连续空格文本。
- 支持中文冒号与英文冒号。
- 提取期数、主题、今日一词、例会经理、日期、起止时间和地点。
- 无年份日期使用当前年份；距离当前日期超过 180 天的过去日期显示警告。
- `[玫瑰]`、`[烟花]`、`待报名`、`空`、`TBD` 和空值归一为 `待定`。
- 同一期重复接龙合并，真实姓名覆盖占位符；多个真实值冲突时采用后出现的值。
- 完整接龙原文保留在黄色粘贴区；灰色提示区明确提醒用户核对解析预览未显示的内容，避免未识别文本被静默忽略。
- 三官在开场分别生成时间官、语法官和哼哈官宣言，在反馈分组分别生成对应报告；负责人引用相应角色。

解析预览与当前 A4 来源分离。用户可先检查解析结果，再切换来源，或在修正列中纠正个别字段。

## 自动排程

排程使用真实 Excel 日期和时间值，不使用文本时间参与计算。

- 每项保存“时长显示”和“排程分钟”两个字段。
- `5-7`、`20min/人` 等文本只用于展示。
- 下一项开始时间等于上一项开始时间加排程分钟。
- 分组行不占用时间。
- 缺少或非法排程分钟时显示警告，并阻止后续时间悄悄产生错误值。
- 预计结束时间超过会议结束时间时显示超时分钟数。

## 视觉规范

- 主色：Toastmasters 深蓝与酒红。
- 强调色：浅蓝、浅绿、浅灰与少量暖黄色警告色。
- 中文字体优先使用微软雅黑或等线；英文与数字使用兼容的无衬线字体。
- 卡片采用细灰边框、白底和紧凑留白；不使用 Excel 默认彩色表格样式。
- 时间和分钟使用统一数字格式，确保列对齐。
- 负责人为空时显示琥珀色 `待定`。
- 打印必须在彩色和灰度环境下都能通过文字、边框和明度区分信息，不只依赖颜色。

## 无宏交互替代

- 网页按钮与弹窗：改为下拉框、表格输入区和解析预览。
- 确认接龙导入：改为将议程来源切换为 `接龙导入`。
- 模板切换：改为来源与模板两个下拉框。
- 添加、删除、排序：使用 Excel 表格行操作和排序功能。
- 首次使用引导：改为操作台说明、单元格批注和颜色图例。
- 自动保存与多设备同步：改为 OneDrive 或 SharePoint。
- PDF 导出：使用 Excel 原生“导出/另存为 PDF”或打印功能。

## 错误处理与保护

- 输入错误通过数据验证、条件格式和明确中文警告显示。
- 所有可能找不到数据的公式必须使用有意义的空态或警告，不直接暴露公式错误。
- 计算区和 A4 公式区默认保护；输入区保持可编辑。
- 关键公式区域提供可见的状态检查，包括来源行数、最终行数、超出页数和公式错误数。
- 不使用易失性函数完成核心逻辑，避免大型工作簿重算缓慢。

## 验收标准

1. 用户示例接龙能提取会议期数、主题、今日一词、经理、日期、时间、地点和角色。
2. 占位符统一为 `待定`，重复帖子合并时真实姓名优先。
3. 三官分别生成开场宣言和反馈报告，并保留对应负责人。
4. 常规例会与即兴马拉松模板可通过下拉框切换。
5. 手工修正优先于来源数据，清空后恢复自动值。
6. 开始时间按排程分钟正确递推，分组不占时间。
7. 30 项以内在 A4 单页完整显示，无裁切、重叠或不可读缩放。
8. 超过 30 项时显示容量警告，并在扩展页保留全部数据。
9. 输出 PDF 的文字、边框、图片和二维码清晰，版式尽量接近当前 HTML 成品。
10. 关键区域不存在 `#VALUE!`、`#REF!`、`#SPILL!`、`#N/A` 或循环引用。
11. 工作簿不包含 VBA 宏、Office Scripts 或外部加载项，打开时不要求启用内容。

## 非目标

- 不在首版中连接 Supabase 或复刻浏览器 `localStorage`。
- 不实现网页式拖拽、模态弹窗、动态引导遮罩或移动端响应式界面。
- 不保证旧版 Excel 2019/2021 支持全部公式。
- 不追求与 HTML 每个像素完全一致；优先保证 Excel 可编辑、可维护和打印稳定。
